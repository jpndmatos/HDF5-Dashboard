# HDF5 Dashboard

Flat sensor-data workbench. Preserve the blue accent, Poppins face, the two chart element IDs, reset button, and theme checkbox. Use CSS tokens for all colors and fonts, 8px corners, 44px controls, visible keyboard focus, light and dark surfaces. Temperature and humidity use separate plotting domains so different units never imply a correlation. The heatmap includes every sensor position from the bundled HDF5 file; time is elapsed recorded seconds. No marketing content, decorative shapes, fake metrics or gradients outside the heatmap scale.
